# REQ-RCT-004: EditText Component

## Description
EditText input component must support label, error state, and leading/trailing icon slots.

## Acceptance Criteria
- [ ] Label renders and associates with input
- [ ] Error state changes border/text color
- [ ] Leading slot renders before input
- [ ] Trailing slot renders after input
- [ ] Extends HTMLInputElement props
