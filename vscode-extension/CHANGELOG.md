# Changelog

All notable changes to the TAK Dark Theme extension will be documented in this file.

## [0.1.0] - 2026-04-19

### Added

- Initial release of TAK Dark Theme
- Editor, sidebar, title bar, and panel background colors from TAK design tokens
- Syntax highlighting for comments, keywords, strings, numbers, functions, types, and variables
- Terminal color scheme matching the editor theme
- Activity bar and status bar styling
